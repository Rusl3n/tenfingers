# Участие в разработке

[English version](CONTRIBUTING.en.md)

Спасибо, что хотите помочь «Десяти пальцам»! Приложение — нативный тренажёр печати для macOS (Swift 6.2, SwiftUI, SwiftData).

## Ошибки и идеи

- Нашли ошибку — откройте [issue](https://github.com/Rusl3n/tenfingers/issues/new/choose) по шаблону «Ошибка»: версия приложения (видна в «О программе»), версия macOS, раскладка, что делали и что получилось.
- Идею оформите шаблоном «Идея». Писать можно по-русски или по-английски.

## Сборка и тесты

Требования: macOS 15 и новее, Xcode 26 и новее.

```bash
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
swift test
./scripts/build-app.sh
```

`build-app.sh` собирает релизную версию, подписывает её ad-hoc, делает резервную копию прогресса (`~/Library/Application Support/TenFingers.backups`) и устанавливает приложение как `/Applications/TenFingers.app`. Только собрать бандл, ничего не устанавливая, — `./scripts/make-bundle.sh [--output DIR]`.

## Pull request

- Работа идёт в отдельной ветке, в `main` — только через pull request.
- Перед PR должны проходить `swift test` и сборка без предупреждений; то же проверяет CI (`.github/workflows/tests.yml`, предупреждения компилятора — ошибка).
- Каждое изменение — вместе с тестами: сначала тест и красный результат, потом код и зелёный.
- Заметное для пользователя записывается в `CHANGELOG.md`, раздел `[Unreleased]` (Добавлено, Изменено, Исправлено).

## Код

- Чистая логика живёт в `TypingCore` (без AppKit, SwiftUI, Carbon, AVFoundation) и покрыта тестами на Swift Testing. Тесты, которые вызывают Carbon TIS, помечаются `@MainActor`.
- Новые строки интерфейса добавляются в оба языка: `Localization/{ru,en}.lproj/Localizable.strings` (для ядра — `Sources/TypingCore/Resources/{ru,en}.lproj`). Тест-сторож проверяет перевод. Язык исходных строк — русский.
- В интерфейсе нет эмодзи — только SF Symbols.
- В репозитории (код, тексты, документы) не упоминаем названия чужих продуктов — только нейтральное описание, например «адаптивный тренажёр, открывающий буквы по мере освоения». Исключение — источники данных и лицензии. Это проверяет `./scripts/check-names.sh` в CI.

## Сохранность данных

Прогресс пользователей терять нельзя.

- Схема базы меняется только аддитивно: новые модели, новые поля — только со значениями по умолчанию. Никаких переименований и удалений полей.
- Если схема меняется, повышается поколение схемы (`SchemaGeneration.swift`); приложение отказывается открывать базу более нового поколения.
- Для проб не трогайте свою папку `~/Library/Application Support/TenFingers` — работайте с копией.
