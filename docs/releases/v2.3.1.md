# Десять пальцев 2.3.1

Дата: 2026-11-04. Полный список изменений: [CHANGELOG.md](../../CHANGELOG.md).

Установщик в релизах: к версии приложены `.dmg` и `.zip`. Само приложение не менялось, схема базы та же (поколение 6, как в 1.2.0); прогресс, история, серия, ачивки и резервные копии сохраняются.

### Добавлено

- К каждому релизу на GitHub теперь приложены установщик `.dmg` (с ярлыком «Программы» для перетаскивания) и архив `.zip`, а также файлы `release.json` и `SHA256SUMS` для проверки загрузки. Собирает их автоматическая сборка по тегу версии; релиз сначала создаётся черновиком.

### Изменено

- README: раздел «Установка» описывает установку из `.dmg`, первый запуск неподписанного приложения и обновление; сборка из исходников осталась запасным путём. В CONTRIBUTING описано, как выпустить версию.
- Сборка бандла приложения вынесена в общий скрипт, которым пользуются и `build-app.sh`, и автоматическая сборка релиза.

## Как установить

1. Скачайте `TenFingers-2.3.1.dmg` из этого релиза, откройте его и перетащите «Десять пальцев» (`TenFingers`) в «Программы». Требуется macOS 15 или новее. Вместо `.dmg` можно взять архив `TenFingers-2.3.1.zip`.
2. Приложение не нотаризовано, поэтому при первом запуске macOS его остановит. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» либо выполните в Терминале `xattr -dr com.apple.quarantine /Applications/TenFingers.app`.
3. Проверить загрузку можно по `SHA256SUMS`: `shasum -a 256 -c SHA256SUMS`.

## Совместимость

- Схема базы — поколение 6, как в 1.2.0, 2.0.0, 2.1.0, 2.2.x и 2.3.0, и не менялась: база 2.3.0 открывается без преобразований, и версия 2.3.0 её тоже откроет.
- История, серия, заморозки, ачивки, прогресс курса, свои тексты и резервные копии сохраняются как есть; файлы прогресса — версия 2, формат не менялся.
- Если вы уже пользуетесь 2.3.0, обновление необязательно: приложение то же.
