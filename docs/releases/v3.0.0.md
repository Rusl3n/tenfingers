# Десять пальцев 3.0.0

Дата: 2026-11-07. Полный список изменений: [CHANGELOG.md](../../CHANGELOG.md).

Профили: несколько учеников на одном Mac. Прогресс, история, серия, ачивки и резервные копии сохраняются; нынешние данные становятся первым профилем.

### Добавлено

- Профили: на одном Mac могут заниматься несколько учеников, у каждого свой прогресс, огонь, ачивки и настройки. Профиль переключается строкой профиля внизу боковой панели или меню «Профиль»; смена выполняется перезапуском приложения. Новый профиль начинает со знакомства. Переименовать и удалить профиль можно в «Управлять профилями»; удалённый профиль уходит в Корзину. Паролей нет.
- Нынешние данные становятся первым профилем — без переноса и преобразований.
- Общие для всех профилей настройки Mac: язык интерфейса, масштаб, размер и сдвиг клавиатуры, проверка обновлений, закрытие приложения вместе с окном, сдвиг звука в «Ритме».
- Язык курса — строка «Курс: Русский» наверху боковой панели (меню).

### Изменено

- Виджет показывает открытый профиль и обновляется сразу после смены профиля; напоминания — тоже открытого профиля.
- Резервные копии и обновление приложения охватывают все профили.
- Загрузка архива прогресса больше не меняет общие настройки Mac (масштаб, клавиатуру). Если загружается архив другого профиля, приложение предупреждает.
- Замер скорости теперь всегда берёт слова по всем буквам, цифрам и знакам — независимо от пройденной части курса.
- Окно, открытое во весь экран, остаётся во весь экран после смены профиля.
- Откат на 2.9.x: старая версия видит только первый профиль (его данные целы), остальные профили она не видит и не портит.

## Как установить

1. Скачайте `TenFingers-3.0.0.dmg` из этого релиза, откройте его и перетащите «Десять пальцев» (`TenFingers`) в «Программы». Требуется macOS 15 или новее. Вместо `.dmg` можно взять архив `TenFingers-3.0.0.zip`.
2. Приложение не нотаризовано, поэтому при первом запуске macOS его остановит. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» либо выполните в Терминале `xattr -dr com.apple.quarantine /Applications/TenFingers.app`.
3. Проверить загрузку можно по `SHA256SUMS`: `shasum -a 256 -c SHA256SUMS`.
4. Если у вас 2.4.0 или новее, приложение само предложит обновление: плашка «Доступна версия X» на «Главной» или «Настройки → Общие → Проверить сейчас». Перед заменой приложение делает резервные копии базы и прогресса в `TenFingers.backups/before-update-*`.

## Совместимость

- Нынешние данные становятся первым профилем без переноса; прогресс, история, серия, ачивки и резервные копии сохраняются.
- Перед первой установкой стоит сохранить копию прогресса (`./scripts/pin-backup.sh before-phase8d`).
- Откат на 2.9.x: старая версия видит только первый профиль, его данные целы; остальные профили она не видит и не портит.
