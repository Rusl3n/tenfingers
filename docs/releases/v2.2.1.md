# Десять пальцев 2.2.1

Дата: 2026-11-01. Полный список изменений: [CHANGELOG.md](../../CHANGELOG.md).

Ачивки снова после каждого шага урока. Схема базы не менялась (поколение 6).

### Изменено

- Ачивки урока проверяются после каждого завершённого шага, как до 2.2.0: карточки — на экране «Готово: шаг N», итог урока показывает всё полученное за урок (решение пользователя: не ждать конца урока). Порции тренировки, практики и «Пальцев» — без изменений.

### Исправлено

- Уход с экрана «Ачивки» больше не перезаписывает уже просмотренные получения (у ачивок за время суток их сотни).
- Сессия с датой в будущем (сбитые часы) больше не заставляет каждую проверку ачивок перечитывать всю историю.
