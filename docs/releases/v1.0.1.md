# Десять пальцев 1.0.1

Дата: 2026-10-24. Полный список изменений: [CHANGELOG.md](../../CHANGELOG.md).

Патч к 1.0.0: исправления по итогам проверки 1.0.0 и новое правило для ачивок скорости, «Снайпера» и «Без подглядывания». Схема базы не менялась (поколение 3), прогресс сохраняется при обновлении.

### Исправлено

- Загрузка прогресса из файла версии 0.3.0 (поколение схемы 2) больше не сбрасывает «Взрослый юмор» и опции карточки «Поделиться» к значениям по умолчанию: в таком файле этих настроек ещё не было, поэтому текущие значения сохраняются.
- «Поделиться…»: каждая карточка пишется во временную папку отдельно, а не на место прежней, поэтому быстрая повторная отправка не отнимает файл у ещё идущей (например, AirDrop). Карточки старше 10 минут удаляются при следующей отправке.
- «Сохранить PNG…» открывает окно сохранения листом на окне «Поделиться», а картинка рисуется после выбора файла.

### Изменено

- Скорость, «Снайпер» и «Без подглядывания» засчитываются и на проверке урока любой длины (шаги курса около 90 знаков, а раньше нужен был текст от 300 знаков); скорость — только без единой ошибки. Рекорды аналитики по-прежнему считаются по упражнениям от 300 знаков, уже полученные ачивки не отзываются.
- После обновления ачивки по новому правилу выдаются из истории с датой проверки урока; «Без подглядывания» теперь можно получить на проверках этапов со скрытыми подсказками.
- Карточка «Последняя ачивка» на главной выбирает запись, не собирая весь список ачивок; проверка ачивок по истории не создаёт календарь на каждый день.
- Спецификация, §21: какие ачивки история не позволяет выдать или точно датировать («Стальные мизинцы», «Три звезды везде», счётчики, дни без упражнений).

## Как установить из исходников

Требования: macOS 15 и новее, Xcode 26 и новее.

```bash
git clone https://github.com/Rusl3n/tenfingers.git
cd tenfingers
git checkout v1.0.1
./scripts/build-app.sh
```

Скрипт собирает релизную версию, подписывает её ad-hoc и копирует в `/Applications` как «Десять пальцев». Перед установкой он делает резервную копию прогресса.
