# Десять пальцев 3.0.2

Дата: 2026-11-11. Полный список изменений: [CHANGELOG.md](https://github.com/Rusl3n/tenfingers/blob/main/CHANGELOG.md).

Скорость на карте курса и цель «Ускорения» — по лучшей попытке, «Шаг заново» у продолженного урока. Схема базы и файл прогресса не менялись (поколение 10 и версия 6, как в 3.0.0); прогресс, история, серия, ачивки, профили и резервные копии сохраняются.

### Изменено

- Номер версии внизу боковой панели стоит по центру, а не у правого края.
- Карта курса: скорость шага — та, с которой пройдена его лучшая попытка (самая точная), а не самая высокая из всех. Повторили шаг ради чистоты: было 2 ошибки на 280 зн/мин, стало 0 на 250 — в строке будет 0 ошибок и 250. Скорость урока — его лучшей проверки.
- «Ускорение»: средняя для цели считается так же — по лучшей попытке каждого шага, и повторы одного шага не заполняют окно из 30 шагов. Быстрые попытки с ошибками больше не задирают цель выше скорости чистой печати.
- Урок, продолженный с середины: на плашке «Продолжаем с шага N из M» вместо «Начать урок заново» — «Шаг заново». Она перезапускает только текущий шаг, пройденные шаги урока остаются.
- «Повторить шаг» (после перебора ошибок) и «Шаг заново» дают тот же шаг с новым текстом, как при входе в шаг с карты курса, а не прежний текст.

## Как установить

1. Скачайте `TenFingers-3.0.2.dmg` из этого релиза, откройте его и перетащите «Десять пальцев» (`TenFingers`) в «Программы». Требуется macOS 15 или новее. Вместо `.dmg` можно взять архив `TenFingers-3.0.2.zip`.
2. Приложение не нотаризовано, поэтому при первом запуске macOS его остановит. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть» либо выполните в Терминале `xattr -dr com.apple.quarantine /Applications/TenFingers.app`.
3. Проверить загрузку можно по `SHA256SUMS`: `shasum -a 256 -c SHA256SUMS`.
4. Если у вас 2.4.0 или новее, приложение само предложит обновление: плашка «Доступна версия X» на «Главной» или «Настройки → Общие → Проверить сейчас». Перед заменой приложение делает резервные копии базы и прогресса в `TenFingers.backups/before-update-*`.

## Совместимость

- Схема базы — поколение 10, файл переноса прогресса — версия 6, как в 3.0.0 и 3.0.1: с 3.0.x обновление проходит без преобразований.
- С 2.9.x обновление тоже без преобразований базы; профили появляются, как в 3.0.0 (нынешние данные — первый профиль).
- Виджет и `widget.json` не менялись.

### Установка

1. Скачайте `TenFingers-3.0.2.dmg` ниже, в разделе **Assets**, откройте его и перетащите «Десять пальцев» в «Программы». Нужны macOS 15 или новее и Mac с процессором Apple (M1 и новее).
2. Первый запуск: приложение не нотаризовано Apple, поэтому macOS его остановит. Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**, либо выполните в Терминале `xattr -dr com.apple.quarantine /Applications/TenFingers.app`.
3. Если уже стоит версия 2.4 или новее — она предложит обновиться сама; прогресс сохраняется.

Подробно, с первой настройкой и сборкой из исходников: [инструкция по установке](https://github.com/Rusl3n/tenfingers/blob/main/docs/INSTALL.md). Проверка файла: `shasum -a 256 TenFingers-3.0.2.dmg` должна совпасть со строкой в `SHA256SUMS`.

### Installation (English)

Download `TenFingers-3.0.2.dmg` from **Assets** below and drag TenFingers into Applications (macOS 15+, Apple silicon). On first launch, allow it under **System Settings → Privacy & Security → Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/TenFingers.app`. Full guide: [installation and setup](https://github.com/Rusl3n/tenfingers/blob/main/docs/INSTALL.en.md).
